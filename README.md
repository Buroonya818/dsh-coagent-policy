# DSH Co-agent 模型白名单

为 **DeepSeek Harness Desktop 0.2.2-rc.3** 提供独立的 `Co-agent 白名单` 预设。主模型照常选，子代理只能使用用户允许的提供方、模型和推理档位。未选择其他预设或修改默认预设。

## 安装与使用

1. 在桌面 App 的「插件 → 添加插件」粘贴 `github:Buroonya818/dsh-coagent-policy#v2.0.1`；或者下载该版本源码，解压后在同处选择含有 `package.json` 的本地目录。提示重启时请保存工作并重启 App。
   v2.0.1 修复桌面设置无法读取模型目录、模型复选框无法使用的问题，升级不更改现有名单或速度。
2. 在「设置」里点「Co-agent 模型」（位于社区「插件市场」旁）；也能打开宿主「插件 → 已安装 → Co-agent 模型白名单」的配置页。社区市场中可从「设置 → 插件市场 → 已安装」搜索 `dsh-coagent-policy`。本机安装不等于已被社区公开目录收录。
3. 需要启用共用名单时，勾选「为所有主模型启用共用名单」。从当前模型目录勾选一项或多项允许的子模型；可为每项选模型支持的推理档位，或保留「模型默认」。点击「保存更改」。
4. 在「编辑常用模型」多选，并保存。常用项在上方置顶，不等于准许委派。
5. 新建会话，选择「Co-agent 白名单」预设，再选择任意主模型。只勾一项时使用这一项；多选时由主模型从名单中选择，每次委派只启动一个子代理。

## 速度和限制

- 目录列出 DSH 当前可用的提供方和模型，使用它们公布的推理档位。没有公布档位的模型使用自身默认值。已保存但不可用的模型会保留记录；委派时拒绝不可用模型，不换其他模型。
- 在安装并启用兼容版本的 Codex 订阅插件时，界面可显示订阅目录公布的 Normal（标准）/ Fast / Ultrafast 能力，并独立应用 **全局** Codex 速度。该版本没有子代理专用的速度接口；应用全局速度会影响支持它的 Codex 会话，也可能增加用量。保存白名单不会更改速度。`Ultra` 推理档位和 `Ultrafast` 速度是不同选项。
- 旧版 Astra/Sol 的名单在用户明确保存共用名单之前继续生效；其他主模型使用两份旧名单的共同项（初始均为 Luna Max）。首次迁移预填旧名单的并集，请检查后再保存。
- 只约束使用本预设的新原生委派，不改变其他预设、已经运行的子代理或直接使用 shell 的能力。该预设保留正常编码工具，但不开放原生 fork、workflow 等额外委派入口。

## 测试

`tests/desktop.mjs` 使用已安装的 Desktop Electron Node 模式及对应 DSH 模块测试设置 schema、旧配置、模型与档位选择、失败和取消路径；假模型后端不发送实际订阅请求。需传入桌面安装的 `DSH_INSTALL_DIR`，以 `ELECTRON_RUN_AS_NODE=1` 运行 `DeepSeek Harness.exe --expose-internals --test tests/desktop.mjs`。
